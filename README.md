# CLAIM — 国别气候综合评估模型

CLAIM 是一个**国别分辨率**的气候-经济综合评估模型（integrated assessment model, IAM），
把 FaIR 碳循环-气候链、MESMER 区域降尺度、以及一套由实证脉冲响应反演出来的
**国别损害核**接在一起，输出逐国逐年的气候损失与碳社会成本（social cost of carbon, SCC）。

它与多数 IAM 的区别在损害端：损害函数不是设定的，而是从
Bilal & Känzig 式的面板局部投影（local projection, LP）响应**反演**出来的，
并且显式建模了资本积累这条次级通道——所以「生产率被打击多少」与
「观测到的产出掉了多少」在模型里是两个不同的量。

## 1. 快速开始

需要 **Julia 1.12**（1.8.1 亦可）。首次运行会编译约 1 分钟，之后每次约 4 秒。

```julia
include("src/MimiCLAIM.jl")

m = get_model(:national; climate=:fair, scenario="ssp245", end_year=2100)
run(m)

scc = compute_scco2(m; year=2030, last_year=2100)
```

本快照的自检值：

```
compute_scco2(get_model(:national; climate=:fair, scenario="ssp245", end_year=2100);
              year=2030, last_year=2100)  ==  690.4507205341098
```

**拿到本包后请先跑这一行。** 数值不符说明数据不完整或 Julia/依赖版本不同，
先解决它再看别的结果。

`src/MimiCLAIM.ipynb` 是**面向用户的主入口**，内含完整的建模、绘图与
不确定性分析流程；`src/MimiCLAIM.jl` 是给脚本调用的精简库入口，两者的
`get_model` 行为一致。

完整的构建、运行与 SCC 说明见 **`CLAIM_model_guide.md`**。

## 3. 两档发行：基础包与可选组件

整个包里有**一个** 110 MB 的大文件，而它只服务于一个功能。所以分两档：

| 档 | 体积 | 能做什么 |
|---|---|---|
| **基础包** | **约 74 MB** | 建模、跑任意情景、点估计、**SCC**、逐国损失、notebook 的全部图表 |
| **+ 可选组件** | +110 MB | 额外可跑**外层不确定性 MC**（气候 / 损害 / 联合三个口径） |

可选组件就是这一个文件：

```
data/unshared_parameters/climate_grid_innov_chol.csv
  SHA-256  4265616099C20059E13CE981677F15784A3751EE6F9305EAD41CD3F0EE3CA71F
  字节数    115,241,260
```

**放回原位即可生效**，不需要改任何配置——代码按固定路径找它。

### 它是什么、为什么可以分开

它是 MESMER 局地变率**新息协方差的下三角 Cholesky 因子**，以稀疏三元组
（`row,col,value`，400 万行）存储 5940 个陆地格点的下三角。用途是把独立正态新息
变换成**带正确空间相关结构**的天气变率场——也就是说，只有在**重新抽样**局地天气时才需要它。

模型跑基准与脉冲两轨用的是**已经生成好**的 `climate_region_lv.csv` 等国家级序列，
所以 `get_model` / `run` / `compute_scco2` 完全不碰这个文件。

**这一点是实测的，不是推断**：把该文件删掉后重跑，SCC 仍是 `690.4507205341098`，
与完整包逐位一致；而外层 MC 的入口会明确报
`missing MESMER grid parameter file: ...climate_grid_innov_chol.csv`。

### 缺了它会怎样

不会静默降级——`run_scc_mc(...; sample_mesmer=true)` 直接报错并指名缺哪个文件。
**不存在「以为跑了 MC、其实没抽样」的可能。**

> ⚠️ **但请记住第 4 节的第 ② ③ 条**：本模型的点估计**不得单独引用**。
> 只用基础包意味着你拿不到不确定性区间，那么引用时必须显式说明
> 「未做不确定性传播」，而不是把点估计当作结果本身。

## 4. 引用结果时必须一起声明的三件事

这三条不是免责声明，是**结果的一部分**。省掉任何一条都会让数字被误读。

**① 这是 market-output partial SCC，不是完整 SCC。**
模型只核算**市场产出**损失，不含非市场损害，**不使用统计生命价值（VSL）**。
文献里那些很大的死亡率 partial SCC 几乎全部来自 VSL，**不可与本模型数字直接相加或比较**。

**② 点估计不得单独引用。** SCC 对参数是非线性的，均值不等于点估计
（实测 Jensen 缺口 +1.7%）。而且损害层的分布**左尾过零**：
$P(\mathrm{SCC}<0)=6.7\%$。报点估计时必须同时报期望与区间。

**③ 现有区间仍不是完整不确定性区间。** 外层 MC 抽的是 6 个 pooled 回归系数与
气候层，**国别核形状参数 `B`/`D` 在传播中被冻结**；气候层本身也是下界
（单一 ESM 的局地变率、无性能加权）。详见 `CLAIM_model_guide.md`。

**④ 情景不是纯粹的 SSP，而是「以实测 2024 年排放重基准后的 SSP」。**
排放输入的 **2016–2024 段已换成实测清单**（EDGAR-2025 + CEDS v_2025_03_18 + GFED5.1），
**2025–2500 段按实测 2024 年水平整体重基准**。原因：SSP 情景在 2015 年就分叉，
而模型的损害起始年是 2025——那十年本该是已经发生的事实，原情景却把 2020 年的
新冠停摆完全漏掉了（CO₂ 高估约 4%）。校正后模型 2024 年的 CH₄ 浓度误差由
−21.3 ppb 变成 +10.9 ppb。

代价是**整条未来路径被一个常数倍率缩放**，倍率逐情景不同（ssp245 为 1.0234，
ssp119 为 1.2974）。乘法缩放精确保留净零年份，但**低排放情景的负排放也被同比例
放大**——`ssp119` 隐含了比原情景多约 30% 的碳移除。跑 `ssp119`/`ssp126` 时务必声明。
完整说明见 `CLAIM_model_guide.md` §4.1.1。

## 5. 已知的结构性限制

| 限制 | 后果 |
|---|---|
| 折旧率 $\delta$ 两轨共用 | 不建模风暴洪水直接毁资本 ⟹ **低估** |
| 储蓄率 $s$ 两轨共用 | 不建模面对损害主动调整储蓄 ⟹ **高估** |
| 上面两条方向相反 | **净偏误方向未知**，两条必须一起说 |
| 损害核 $B$ 的下界是外推先验 | 11 年估计窗口对窗口外的持续性没有信息；该先验值约 4% 的 SCC |
| 资本递归取线性化 | 产出路径误差 ~1.6%；但边际响应不随已积累损害变化（真实经济应当变化） |

## 6. 本包**不含**什么

- **标定链**：MESMER 网格训练、FaIR 约束集抽样、损害核反演等上游脚本与其原始输入
  （体量 33 GB，且部分是第三方 ESM 原始数据，另有再分发许可问题）。
  本包提供的是**标定完成后的参数**，可直接运行，但不能从头重跑标定。
- **测试与研究脚本**：留在研究仓库内。
- **回归与反演阶段**：损害核由面板局部投影反演得到，那一阶段属于上游研究流程。

需要复现标定链或反演，请联系作者索取研究仓库。
